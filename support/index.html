Frequently asked questions

Is my progress saved? What about a new phone?

Progress is saved on your device and backed up to your game account's cloud save when you are online. On a new device, open the game and restore from the cloud save. Uninstalling the game removes the local copy, so make sure you have synced first.

How do I delete my account and data?

Open the game and go to Settings → Save your progress → Delete account, then confirm. This removes your friend code, invites, friendships, cloud save and profile from our server. Can't open the game? See Delete your account, and the Privacy Policy.

What is a friend code and how do invites work?

Every player gets a friend code of 8 letters and digits (shown like ABCD-EFGH). Share your code or invite link from Settings → Friends. To use a code you were given, open Settings → Friends → I was invited and enter it. Invite codes can be entered within 7 days of installing. An invite link looks like https://tontechco.github.io/saffronstreet-site/i/ABCDEFGH and opens a page with the code and a download button.

My friend's invite link says the code is invalid.

Codes use only the digits 0-9 and the letters A-Z without I, L, O and U. Check for typos and try typing the code in the game instead. If it still fails, email us the code.

How do I turn notifications on or off?

The game uses local reminders on your device (for example when energy is full). Manage them in the game's Settings, or in your device settings: iOS Settings → Notifications → Saffron Street, or Android Settings → Apps → Saffron Street → Notifications.

Which languages are supported?

English, German, French, Spanish, Italian, Brazilian Portuguese and Hebrew. Change the language in the game's Settings.

Is the game on Android?

Yes, Saffron Street is coming to Google Play as well as the App Store, and accounts work across iPhone and Android.

Do I have to play Service Shifts?

No. Service Shifts are always optional, and every chapter can be finished without them.

How do I report or block another player?

Open the player in Settings → Friends and choose Report or Block. There is no text chat in the game; players only use emotes.

Response time
